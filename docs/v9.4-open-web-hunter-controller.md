# v9.4 Open-Web Hunter Controller

v9.4 stitches the v8/v9 pieces into a bounded controller:

```text
Map -> Calculate -> Scroll -> Remap -> Fire
```

The controller lives at the script layer, not inside `genesis-os-driver`.
`os-driver` remains a physical mechanism. The hunter loop is policy, so it is
kept observable, bounded, and easy to kill.

## Control Contract

- Default mode is dry-run and performs one projection step only.
- Armed mode requires both keys:

```bash
GENESIS_V94_ARMED_CONFIRM=GENESIS_V94_ARMED_OPEN_WEB_HUNTER \
GENESIS_V94_AUTO_FIRE_CONFIRM=GENESIS_V94_AUTO_FIRE_HUNTER_SHOT \
./scripts/run_v94_open_web_hunter_controller.sh
```

- The loop is bounded by `GENESIS_V94_MAX_STEPS` (default `4`).
- Each step remaps before deciding whether to scroll or fire.
- The calculated scroll remains an undershooting proposal; the next Remap is
  still the only truth source.
- Armed mode performs a scroll-progress audit after each Remap. If the same
  target does not move by at least `GENESIS_V94_SCROLL_PROGRESS_EPS` pixels
  (default `2.0`) for `GENESIS_V94_MAX_NO_PROGRESS_STEPS` consecutive Remaps
  (default `2`), the controller stops with `stop_reason=scroll_no_progress`.
  This turns swallowed or misdelivered scroll events into explicit telemetry
  instead of exhausting the full step budget silently.
- Missing targets are first-class telemetry: the controller emits
  `target_found=false`, stops with `stop_reason=target_not_found`, and posts no
  scroll or click.
- Before mapping, the controller requires the front browser URL to settle on
  the requested target URL. A stale foreground tab is treated as an environment
  failure, not as a valid hunting field.

## Validation

```bash
./scripts/validate_v94_open_web_hunter_controller.sh
```

The validation path asserts:

- one read-only map,
- one calculated undershooting scroll plan,
- one unarmed OS-driver scroll receipt,
- one negative target-not-found redline,
- no click, no URL change, and no physical posting.

This proves the controller can stitch the loop without silently inheriting
permission to act.
