# Genesis v10.4 Open-Web AX Tractor Hunt Report

## Summary

v10.4 completed the first open-web target-driven hunt using the WebKit
Accessibility control plane for motion and the existing OS driver for the final
physical click.

The loop was:

```text
Shadow Map -> AXScrollToVisible -> Remap -> Occlusion Court -> Move/Click -> URL Assertion
```

## Interpretation

The AX traction step moved the offscreen WebKit target into a safe viewport
position without physical input. The remap and occlusion court then confirmed
the final shot was visible and unobstructed before the OS driver posted exactly
one physical move and one physical click.

The URL remained unchanged after AX traction and changed only after the click,
which preserves the causality boundary between control-plane positioning and
physical action.
