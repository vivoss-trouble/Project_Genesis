# Genesis v14.5a Public Obstacle Recon

v14.5a moves the obstacle-clearance stack from local fixtures to a public
demo site, but keeps the probe strictly read-only.

## Target

Default URL:

```text
https://onetrustdemo.com/en/
```

The target is a public OneTrust demo environment. It is used as the first
open-web recon target because the page is designed around consent and privacy
management demonstrations rather than arbitrary commercial conversion flows.

## Recon Rules

The runner never posts physical input:

```json
{
  "posted": false,
  "physical_input_posted": false
}
```

The page is sampled with bounded dynamic polling:

- default timeout: `5000ms`
- default interval: `500ms`
- stop early only after an obstacle with at least one local candidate is seen
- timeout with no obstacle is a valid observation, not a failure

## Arming Gate

The probe may emit `safe_to_arm=true` only when all conditions hold:

- `public_obstacle_seen=true`
- `occluder_kind=modal`
- `legal_candidate_count=1`
- `candidate_count >= 2`
- `rejected_candidate_count >= 1`

This preserves the v13 white-list law. A single close-like control is not
enough to arm v14.5b unless the probe also proves it rejected at least one
blacklisted decoy.

## Commands

Read-only validation:

```bash
./scripts/validate_v145_public_obstacle_recon.sh
```

Override the public target:

```bash
GENESIS_V145_TARGET_URL=https://example.com \
GENESIS_V145_WINDOW_TITLE="Example" \
./scripts/run_v145_public_obstacle_recon.sh
```

## Expected Outcomes

No obstacle:

```json
{
  "public_obstacle_seen": false,
  "safe_to_arm": false,
  "stop_reason": "no_public_obstacle_seen"
}
```

Obstacle found but ambiguous:

```json
{
  "public_obstacle_seen": true,
  "safe_to_arm": false
}
```

Obstacle found and legally armable:

```json
{
  "public_obstacle_seen": true,
  "occluder_kind": "modal",
  "legal_candidate_count": 1,
  "safe_to_arm": true
}
```
