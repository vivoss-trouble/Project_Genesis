v20.1 wraps v20.0 with an immutable evidence pack. The pack captures the read-only plan, step remap evidence, driver receipts, post assertions, terminal scan, raw logs, and a cryptographic manifest.

## Boundary Finding

The evidence pack does not replace v20 execution. It observes and seals it.

The implementation keeps the failure policy asymmetric:

- Missing JSON evidence is fatal.
- Missing screenshots are recorded in `screenshot_status` files.

This keeps the ledger authoritative without making the camera a single point of failure.

- Dry-run pack is created and sealed.
- Armed pack is created and sealed.
- Required JSON evidence files exist.
- Manifest SHA-256 values match actual file contents.
- Step evidence confirms fresh remap and rejects stale plan coordinates.
