# Genesis v8.1 Open-Web Shadow Mapping

v8.1 is a read-only migration step from controlled browser fixtures toward real
web pages.

The invariant is strict:

```text
snapshot -> taxonomy -> geometry -> telemetry
posted=false
os_driver_active=false
```

No OS-driver socket is opened. No click, scroll, keypress, DOM mutation, or
network write is allowed.

## Taxonomy

The first open-web shadow taxonomy is intentionally geometric:

- `heading`
- `link-like`
- `button-like`
- `code-block`
- `scroll-region`

The mapper uses a window-scoped `CGWindowListCreateImage` capture and writes a
debug overlay with bounding boxes and target IDs.

## Deterministic Validation

The redline uses a local static documentation-shaped sample so the taxonomy can
be validated without network drift:

```bash
./scripts/validate_v81_open_web_shadow_map.sh
```

Expected assertions:

- all five taxonomy classes are present
- `posted=false`
- `os_driver_active=false`
- debug overlay exists

## Public Page Probe

To inspect a real public page, override the URL and title needle:

```bash
GENESIS_V81_URL="https://doc.rust-lang.org/book/" \
GENESIS_V81_WINDOW_TITLE="Rust" \
  ./scripts/run_v81_open_web_shadow_map.sh
```

Public probes are telemetry only. They are not redline gates because page
content, fonts, layout, and network state can change.
