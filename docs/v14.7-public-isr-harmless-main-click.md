# Genesis v14.7 Public ISR Harmless Main Click

v14.7 extends the v14.6 public ISR E2E loop with a second physical actuation after obstacle clearance.

The main target is intentionally harmless: it must be static web content inside `AXWebArea`, have no `AXPress` action, and have no interactive ancestor such as `AXLink` or `AXButton`.

## Pipeline

1. Open the W3C modal dialog example.
2. Capture the ground state and select one harmless web-content target.
3. Trigger `Add Delivery Address` to force the modal into `S1`.
4. Detect `occlusion_clear=false` and freeze the main loop.
5. Clear the modal by clicking the only legal whitelist candidate, `Cancel`.
6. Force a fresh v12 remap.
7. Click the harmless main target.
8. Assert that the modal remains absent and the URL is unchanged.

## Armed Gate

```bash
GENESIS_V147_ARMED_CONFIRM=GENESIS_V147_ARMED_PUBLIC_ISR_HARMLESS_MAIN \
GENESIS_V147_AUTO_FIRE_CONFIRM=GENESIS_V147_AUTO_FIRE_PUBLIC_ISR_HARMLESS_MAIN \
./scripts/run_v147_public_isr_harmless_main_click.sh
```
