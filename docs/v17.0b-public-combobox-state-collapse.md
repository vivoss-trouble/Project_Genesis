# Genesis v17.0b Public Combobox State Collapse

## Purpose

v17.0b isolates the Z-axis expansion primitive for public web controls. It
targets the W3C APG select-only combobox example and proves that a bounded
physical click can open the popup, select one option, collapse the popup, and
change the combobox value without submitting a form or changing the current URL.

## Pipeline

```text
Open W3C select-only combobox example
  -> Fresh AX remap
  -> lock one AXComboBox target
  -> AXScrollToVisible pre-traction
  -> Fresh AX remap
  -> record pre_value
  -> physical click combobox
  -> wait for AXList popup and target option
  -> physical click option
  -> Fresh AX remap
  -> record post_value
  -> assert popup collapsed
  -> assert url_unchanged
```

## Red Lines

- GUI/OS armed validation must run serially.
- `AXPress` success is not sufficient evidence.
- The winning receipt is the fresh post-option AX value of the combobox.
- No Submit/Verify path is included in v17.0b.
- `url_unchanged=true` is mandatory.
- Popup expansion must be observed before the option click.
- Popup collapse must be observed after the option click.

## Default Target

- URL: `https://www.w3.org/WAI/ARIA/apg/patterns/combobox/examples/combobox-select-only/`
- Window title needle: `Select-Only Combobox`
- Combobox label: `Favorite Fruit`
- Option label: `Banana`
