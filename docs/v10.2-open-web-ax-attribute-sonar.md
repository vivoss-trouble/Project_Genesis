# Genesis v10.2 Open-Web AX Attribute Sonar

v10.1 proved that Safari exposes an `AXWebArea` and a nearest `AXScrollArea`,
but the visible control surface does not provide a usable page-scroll primitive.
v10.2 is a read-only sonar pass over the WebKit Accessibility tree.

## Boundary

The v10.2 probe is strictly non-mutating:

- no `genesis-os-driver`,
- no `AXUIElementSetAttributeValue`,
- no `AXUIElementPerformAction`,
- no scrollbar writes,
- no physical input.

The only browser state change is loading the authorized target URL before the
probe begins.

## Sonar Scope

`scripts/ax_webarea_attribute_sonar.swift` performs two bounded passes:

1. Locate the top `AXWebArea` under the selected Safari window.
2. Descend from that `AXWebArea` for a small bounded depth, recording:
   - `AXUIElementCopyAttributeNames`
   - `AXUIElementCopyParameterizedAttributeNames`
   - `AXUIElementCopyActionNames`
   - scalar samples for role, title, description, orientation, and value fields

Traversal only descends into container-like roles such as `AXWebArea`,
`AXScrollArea`, `AXGroup`, `AXList`, `AXTable`, `AXRow`, and related structural
containers.

## Output

The sonar emits:

- root `AXWebArea` attributes, parameterized attributes, and actions,
- nearest scroll ancestor attributes, parameterized attributes, and actions,
- bounded sonar nodes,
- scroll suspects,
- parameterized-attribute suspects,
- value-bearing suspects,
- aggregate attribute/action inventories.

`GENESIS_V102_MAX_RECORDED_NODES` defaults to `12` to keep routine logs small.
Increase it only for manual deep dives.

The surrounding run script captures pre/post Shadow Maps and verifies that the
sonar did not move the page or change URL.

## Validation

```bash
./scripts/validate_v102_open_web_ax_attribute_sonar.sh
```

Validation requires:

- `web_area_found=true`,
- `posted=false`,
- `os_driver_active=false`,
- `ax_mutation_attempted=false`,
- `url_changed_after_sonar=false`,
- `visual_change_detected=false`,
- `window_id_stable=true`.
