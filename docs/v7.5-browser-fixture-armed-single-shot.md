# Genesis v7.5 Browser Fixture Armed Single-Shot

v7.5 prepares the first controlled browser live-fire path.

The default validation is still dry-run. Armed mode requires two keys and posts
exactly one click to the local browser fixture.

## Fixture Assertion

`browser-button-a` changes from cyan `button-like` to red `fired-button` when it
receives a real click. The post-click map is the independent visual assertion.

## Dry-Run Validation

```bash
./scripts/validate_v75_browser_fixture_armed_single_shot.sh
```

Dry-run assertions:

- pre-map exists
- OS-driver move/click receipts exist
- `posted=false`
- post-map remains unmutated
- `assert_match=false`

## Armed Single Shot

```bash
GENESIS_V75_ARMED_CONFIRM=GENESIS_V75_ARMED_BROWSER_FIXTURE \
GENESIS_V75_AUTO_FIRE_CONFIRM=GENESIS_V75_AUTO_FIRE_SINGLE_SHOT \
  ./scripts/run_v75_browser_fixture_armed_single_shot.sh
```

Armed assertions:

- one move and one click are posted
- the post-click map contains `fired-button`
- `assert_match=true`

## Invariant

One browser shot, one visual assertion. The live-fire target is local and
side-effect free.
