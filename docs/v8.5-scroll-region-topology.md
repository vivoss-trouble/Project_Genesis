# Genesis v8.5 Scroll-Region Topology

v8.5 adds a read-only containment layer to the open-web shadow map.

The mapper still captures a single window slice and still emits ordinary
`targets[]`. It now also correlates visible targets whose pixel centers fall
inside a detected `scroll-region`.

## Contract

Each child target inside a scroll region receives:

```json
{
  "container_id": "shadow-scroll-region-x108-y99"
}
```

The top-level shadow map also emits:

```json
{
  "scroll_regions": [
    {
      "target_id": "shadow-scroll-region-x108-y99",
      "child_target_ids": ["shadow-heading-x64-y84", "shadow-link-like-x61-y106"],
      "child_count": 2
    }
  ]
}
```

This is not recursive scrolling yet. It is the first containment proof: Genesis
can say which visible tactical targets belong to a scrollable visual boundary.

## Safety

v8.5 is observation only:

- no click
- no scroll
- no keyboard input
- `posted=false`
- `os_driver_active=false`

## Validation

```bash
./scripts/validate_v85_scroll_region_topology.sh
```

The validation asserts that at least one `scroll-region` owns visible child
targets and that every child target points back to the same `container_id`.
