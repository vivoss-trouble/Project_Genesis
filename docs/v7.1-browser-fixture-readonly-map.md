# Genesis v7.1 Browser Fixture Read-Only Map

v7.1 moves Genesis from native Calculator topology into a controlled browser
surface without entering open-web entropy.

## Scope

- `fixtures/v7/browser_fixture.html` is a local, inert HTML battlefield.
- `scripts/browser_fixture_readonly_map.swift` captures the browser window through
  `CGWindowListCreateImage`.
- The mapper emits a dry-run `browser_fixture_readonly_map` event only.
- No DOM is read, no OCR is used, and no OS-driver action is posted.

## Control Taxonomy

The fixture intentionally uses high-contrast rendered controls so the first
browser retina can be pure geometry:

- `button-like`
- `input-like`
- `scroll-container`
- `async-target`

Each component receives:

- `target_id`
- `control_kind`
- `bbox`
- `pixel_center`
- `window_coregraphics_point`
- `global_coregraphics_point`

## Validation

```bash
./scripts/validate_v71_browser_fixture_readonly_map.sh
```

The validation opens the local fixture in Safari by default, waits for the
asynchronous target to appear, captures the browser window, and asserts:

- window-scoped capture
- at least five targets
- all four control kinds
- `posted=false`
- a debug overlay PNG exists

Use another browser with:

```bash
GENESIS_V71_BROWSER_APP="Google Chrome" \
  ./scripts/validate_v71_browser_fixture_readonly_map.sh
```

## Invariant

v7.1 is cartography, not fire control. Browser coordinates may be projected, but
physical actuation remains locked out until the topology is stable.
