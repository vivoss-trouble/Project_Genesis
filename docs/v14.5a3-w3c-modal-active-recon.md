# Genesis v14.5a-3 W3C Modal Active Recon

v14.5a-3 proves the public W3C modal can be deliberately activated and then
audited without OS-driver physical input.

## Sequence

1. Open the W3C modal dialog example.
2. Prove the baseline: `Add Delivery Address` exists and the modal is inactive.
3. Trigger the modal with one confirmed AXPress on the trigger button.
4. Return to read-only polling until a modal appears.
5. Run the local whitelist court inside the modal subtree.

## Arming Standard

`safe_to_arm=true` is allowed only when:

- `public_obstacle_seen=true`
- `occluder_kind=modal`
- `candidate_count >= 2`
- `legal_candidate_count=1`
- `rejected_candidate_count >= 1`

The W3C active modal currently yields `Cancel` as the unique legal clearance
control. `Verify Address`, `Add`, and unrelated browser/autofill controls are
rejected.
