# Genesis v10.4 Open-Web AX Tractor Hunt

v10.4 replaces the old open-web physical scroll hunt with a target-driven
Accessibility control-plane route:

```text
Shadow Map -> AX descendant search -> AXScrollToVisible
Remap -> occlusion court -> os-driver click -> URL assertion
```

## Boundary

Dry-run mode:

- opens a fresh authorized Rust Book Safari document,
- accepts Shadow Maps only from a window whose title matches the authorized
  target title,
- resolves the target through the `AXWebArea` descendant tree,
- verifies the target exposes `AXScrollToVisible`,
- computes the post-traction click point from the AX frame,
- performs no AX mutation and no physical input,
- asserts no URL change.

Armed mode:

- performs one bounded `AXScrollToVisible` action on the verified target,
- remaps the window,
- verifies the target is visible and not under a sticky occluder,
- posts one `move_mouse` and one `click_point` through `genesis-os-driver`,
- asserts the URL changes only after the click, not after AX traction.

## Armed Command

```bash
GENESIS_V104_ARMED_CONFIRM=GENESIS_V104_ARMED_OPEN_WEB_AX_TRACTOR_HUNT \
GENESIS_V104_AUTO_FIRE_CONFIRM=GENESIS_V104_AUTO_FIRE_AX_TRACTOR_HUNT \
./scripts/run_v104_open_web_ax_tractor_hunt.sh
```

## Acceptance

Dry-run acceptance:

- `target_found=true`
- `scroll_to_visible_available=true`
- `ax_mutation_attempted=false`
- `move_posted=false`
- `click_posted=false`
- `url_changed_after_ax=false`
- `url_changed_after_click=false`
- `assert_match=true`

Armed acceptance:

- `ax_mutation_attempted=true`
- `scroll_to_visible_status=success`
- `target_visible_after_action=true`
- `occlusion_clear=true`
- `move_posted=true`
- `click_posted=true`
- `url_changed_after_ax=false`
- `url_changed_after_click=true`
- `assert_match=true`

## Validation

```bash
./scripts/validate_v104_open_web_ax_tractor_hunt.sh
```

Validation remains dry-run and proves that the full controller can resolve the
target and compute the final shot without mutating WebKit state or posting
physical input.
