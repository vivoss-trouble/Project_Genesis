## Scope

This version intentionally targets a public standards fixture with no persistence. It verifies the public controlled mutation path without touching accounts, subscriptions, orders, or consent decisions.

## Finding

Unlike the local v15.5 fixture, the W3C public text field accepted `AXValue` as a real state mutation: the live field value reflected `42 Genesis Way` immediately, so the System Events fallback was not used. This narrows the v15.5 Safari `AXValue` mismatch to target implementation behavior rather than a universal WebKit constant.
