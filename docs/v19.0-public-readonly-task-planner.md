# Genesis v19.0 Public Read-Only Task Planner

## Goal

v19.0 adds a public, read-only task planner that turns a live Web page into an executable task blueprint without posting any physical input. It is the airlock between v18's long-clock business mutation capability and any future public armed run.

The planner is intentionally passive:

- It does not start `os-driver`.
- It does not emit `CGEvent`.
- It does not perform `AXPress`.
- It treats the current page as evidence, not as a script to mutate.

## Default Target

- URL: `https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/examples/dialog/`
- Domain lock: `w3.org/WAI/ARIA/apg/patterns/dialog-modal/examples/dialog`
- Visible trigger: `Add Delivery Address`
- Deferred modal field: `Street`
- Deferred modal commit: `Verify Address`
- Expected terminal evidence: `Verification Result`

The W3C modal is deliberately inactive on load. v19.0 therefore plans a state-activation step and marks the form controls as deferred until the modal exists. This keeps the plan honest: it never claims to see controls that have not yet been materialized.

## Plan Contract

The emitted `v190_public_task_plan` includes:

- `target_sequence`: ordered task steps.
- `control_type_coverage`: observed control kinds in the current AX tree.
- `isr_prediction`: predicted interrupt surfaces, without touching them.
- `domain_lock`: the execution boundary for any later armed mode.
- `termination_conditions`: what future armed execution must prove.
- `safe_to_arm`: a planning-only admission bit.

`safe_to_arm=true` only means the read-only plan is coherent enough to review. It is not an armed execution token.

## Safety Lines

- `posted=false` is mandatory for every plan and plan step.
- `physical_input_posted=false` is mandatory.
- `os_driver_active=false` is mandatory.
- A modal already active on page load is treated as an obstacle, not as a hidden success.
- Deferred controls remain deferred until a future fresh remap observes them.

## Commands

Run the planner:

```bash
./scripts/run_v190_public_task_planner.sh
```

Validate:

```bash
./scripts/validate_v190_public_task_planner.sh
```
