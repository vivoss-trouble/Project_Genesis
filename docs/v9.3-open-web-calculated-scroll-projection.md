# v9.3 Open-Web Calculated Scroll Projection

v9.3 introduces a conservative scroll planner for open-Web maneuvering:

```text
Map -> Range -> Piecewise Damping -> Unarmed Scroll Receipt
```

The planner reduces blind-scroll steps, but it never replaces Remap as the
truth source. Every calculated scroll is treated as a proposal that must be
followed by a fresh visual map before any later fire decision.

## Damping Table

The planner uses a piecewise, undershooting damping table instead of a single
global scalar:

| Distance to safe center | Damping factor | Band |
| --- | ---: | --- |
| `<= safe_band_px` | `0.00` | `in_safe_band` |
| `< 90px` | `0.25` | `micro` |
| `90px - 219px` | `0.45` | `near` |
| `220px - 419px` | `0.60` | `mid` |
| `>= 420px` | `0.75` | `far` |

The resulting absolute scroll delta is still clamped below the measured
distance, so the planner prefers undershoot over overshoot. Undershoot costs
one extra Remap; overshoot can drive the target under a sticky occluder.

## Safety Contract

Validation remains projection-only:

```bash
./scripts/validate_v93_open_web_calculated_scroll_projection.sh
```

It asserts:

- maps remain read-only (`posted=false`, `os_driver_active=false`),
- the OS driver returns an unarmed `scroll_wheel` receipt,
- the planned delta is not the v9.2 fixed `-480` step,
- the calculated delta undershoots the measured target distance,
- no URL change occurs.

v9.3 intentionally does not add an armed gate. Calculated scrolling is a
planner, not a source of truth.
