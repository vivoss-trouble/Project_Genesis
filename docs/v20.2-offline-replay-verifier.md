# Genesis v20.2 Offline Replay Verifier

v20.2 adds an offline court for v20.1 evidence packs. It does not touch the
browser, does not start the OS driver, and does not replay physical input. It
loads a sealed evidence pack, recalculates every manifest SHA-256, and checks
whether the recorded execution obeyed the ZLM contracts.

## Scope

- Verify `manifest.json` schema and append-only file set.
- Recompute SHA-256 and byte length for every recorded artifact.
- Reject missing, extra, or tampered evidence files.
- Audit armed and dry-run mode expectations.
- Validate step ordering: `pre_remap -> driver_receipt -> post_assert`.
- Validate fresh-remap discipline and stale-coordinate rejection.
- Validate armed kinetic evidence presence.
- Emit time-tear warnings using filesystem mtime as advisory telemetry.

## Time Policy

v20.1 packs do not seal per-step UTC timestamps inside the manifest. Because
filesystem mtimes are not cryptographic evidence, v20.2 treats relative time
thresholds as advisory only. Hashes and ZLM contract violations remain fatal.

Future evidence pack versions can promote time-tear thresholds to fatal once
per-step sealed timestamps are included in the manifest.

## Commands

```bash
./scripts/replay_v202_evidence_pack.sh /path/to/evidence_pack
```

```bash
./scripts/validate_v202_replay_verifier.sh
```

Optional report path:

```bash
GENESIS_V202_REPORT_PATH=/tmp/v202_report.json \
./scripts/replay_v202_evidence_pack.sh /path/to/evidence_pack
```

Optional advisory time threshold:

```bash
GENESIS_V202_TIME_TEAR_THRESHOLD_MS=1000 \
./scripts/replay_v202_evidence_pack.sh /path/to/evidence_pack
```

## Fatal Verdicts

- `TAMPERED_EVIDENCE_FATAL`
- `MISSING_EVIDENCE_FATAL`
- `UNMANIFESTED_EVIDENCE_FATAL`
- `REQUIRED_LEDGER_MISSING_FATAL`
- `STALE_COORDINATE_VIOLATION`
- `ARMED_STEP_LEDGER_MISSING_FATAL`
- `ARMED_KINETIC_SOURCE_MISSING_FATAL`
- `RESIDUAL_SOCKET_FATAL`

## Advisory Verdicts

- `SEALED_STEP_TIMESTAMPS_UNAVAILABLE`
- `TIME_TEAR_WARNING`
