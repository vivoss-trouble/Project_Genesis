# Genesis v16.0 Public Controlled Business Mutation

## Goal

v16.0 moves the v15.5 state-mutation path onto a real public HTTPS fixture while keeping the business action non-persistent. It uses the W3C ARIA modal dialog example as a standards-grade public target.

## Target

- URL: `https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/examples/dialog/`
- Trigger: `Add Delivery Address`
- Field: `Street`
- Payload: `42 Genesis Way`
- Commit: `Verify Address`
- Assertion: `Verification Result`

## Flow

```text
S0 public W3C page
  -> AX trigger Add Delivery Address
  -> S1 public modal business surface
  -> locate Street + Verify Address
  -> AXValue write attempt
  -> if WebKit does not reflect AXValue, focus field and type through System Events
  -> OS Driver click Verify Address
  -> fresh AX assertion sees Verification Result
  -> URL remains unchanged
```

## Safety Lines

- Dry-run stops before OS physical input.
- The target is a W3C demonstration form, not a real account, order, subscription, or consent flow.
- `AXValue` success remains only a request receipt. Field readiness is proven by a fresh read of the live field value.
- The fallback text transport is only used after an AX attempt and is audited separately.
- The final assertion must observe `Verification Result` and preserve the URL.

## Commands

```bash
./scripts/run_v160_public_controlled_business_mutation.sh
```
