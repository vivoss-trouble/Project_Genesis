## Design Result

The v21.0a result on Wikipedia was honest but not executable: `plan_ready=false`.

v21.0b makes that failure actionable by teaching the planner a narrow public search profile. The executor still refuses stale plan coordinates and performs a fresh AX remap before the field mutation and before the search submit. Wikipedia exposes offscreen or non-semantic search proxies in Safari, so the armed path focuses the freshly observed search field and clicks the first visible suggestion row instead of trusting stale proxy button frames.

## Redlines

- No stale coordinates.
- Domain lock must remain `wikipedia.org`.
- The armed evidence source is profile-specific and must be present.
- The v20.2 verifier must report `time_tear_fatal_enforced=true`.
- GUI/OS armed validation must be serial.
