# Genesis v17.0a Public Binary State Collapse

## Purpose

v17.0a isolates the discrete-state mutation primitive for public web controls.
It targets the W3C APG two-state checkbox example and proves that a bounded
physical click can toggle one public checkbox/radio target without submitting a
form or changing the current URL.

## Pipeline

```text
Open W3C checkbox example
  -> Fresh AX remap
  -> lock one checkbox/radio target
  -> AXScrollToVisible pre-traction
  -> Fresh AX remap
  -> record pre_state
  -> physical click
  -> Fresh AX remap
  -> record post_state
  -> assert exactly one binary state collapse
  -> assert url_unchanged
```

## Red Lines

- GUI/OS armed validation must run serially.
- `AXPress` or `AXValue` success is not sufficient evidence.
- The winning receipt is the fresh post-click AX state.
- No Submit/Verify path is included in v17.0a.
- `url_unchanged=true` is mandatory.
- Off-screen targets must be pulled into view before physical click delivery.
- State sources are ordered by observed truth value, with `AXValue` before
  `AXSelected` for the W3C checkbox fixture.

## Default Target

- URL: `https://www.w3.org/WAI/ARIA/apg/patterns/checkbox/examples/checkbox/`
- Window title needle: `Checkbox Example`
- Target label: `Lettuce`
- Target kind: `checkbox`

## Physical Constants

- `AXScrollToVisible` is required before the click when the selected checkbox is
  below the visible Safari viewport. Without this traction step, CoreGraphics can
  clamp the click point to the physical screen edge and the target state remains
  unchanged.
- The W3C APG checkbox exposes its post-click truth through `AXValue` (`0`/`1`).
  `AXSelected` can remain false and is not an acceptable primary source for this
  fixture.

## Receipt

```json
{
  "target_kind": "checkbox",
  "pre_state": false,
  "mutation_posted": true,
  "post_state": true,
  "fresh_remap_done": true,
  "state_changed_once": true,
  "url_unchanged": true,
  "business_state_asserted": true
}
```
