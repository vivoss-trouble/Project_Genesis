# v9.5 Open-Web Autonomous Hunt

v9.5 is the final public-Web armed gate. It does not reimplement hunting logic;
it delegates to the bounded v9.4 Hunter Controller and adds a separate launch
and result court.

```text
v9.5 Gate -> v9.4 Hunter -> Map -> Calculate -> Scroll -> Remap -> Fire
```

## Dry-Run Validation

```bash
./scripts/validate_v95_open_web_autonomous_hunt.sh
```

The dry-run path must stop at `dry_run_projection_stop` and keep:

- `posted=false`
- `scroll_posted=false`
- `click_posted=false`
- `url_changed=false`

## Armed Gate

The live autonomous hunt requires v9.5 keys. v9.5 translates them into the
v9.4 keys internally:

```bash
GENESIS_V95_ARMED_CONFIRM=GENESIS_V95_ARMED_OPEN_WEB_AUTONOMOUS_HUNT \
GENESIS_V95_AUTO_FIRE_CONFIRM=GENESIS_V95_AUTO_FIRE_HUNT \
./scripts/run_v95_open_web_autonomous_hunt.sh
```

The armed result court requires:

- `hunter_fired=true`
- `scroll_posted=true`
- `click_posted=true`
- `url_changed=true`

If the delegated v9.4 hunter refuses to fire, v9.5 still emits a
`v95_open_web_autonomous_hunt_summary` before exiting non-zero. The summary
includes `failure_kind`, `hunter_exit_status`, and scroll-progress fields so an
armed failure remains auditable at the launch-gate layer.

This is the first point where the full open-Web maneuver chain is allowed to
cross from projection into real OS-level action.
