# Genesis v14.5a-2 W3C Modal Static Recon

v14.5a-2 establishes a deterministic public modal baseline before any armed
public obstacle clearance.

## Target

```text
https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/examples/dialog/
```

The page is the W3C WAI-ARIA Authoring Practices modal dialog example. It is a
public HTTPS page with a standards-oriented AX/ARIA structure.

## Purpose

The initial page load should be a clean baseline:

- trigger button exists: `Add Delivery Address`
- modal dialog is inactive on load
- no clearance candidate is considered
- `safe_to_arm=false`
- no physical input is posted

The shared W3C recon primitive also contains the v14.5a-3 whitelist court, but
in the static baseline there is no modal subtree to adjudicate.

This creates the before-state for a future v14.5b armed test, where the modal
will be explicitly triggered and then cleared.
