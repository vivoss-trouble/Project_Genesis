# v9.2 Open-Web Maneuver Single-Shot Gate

v9.2 adds a conservative open-web maneuver chain:

```text
Map -> Step Scroll -> Remap -> Select -> Fire Projection -> Assert
```

The strategy is intentionally bounded step scrolling, not calculated one-shot
scrolling. Open Web scroll response is influenced by browser focus, zoom,
inertia, page height, and the active hit-test region. v9.2 records the first
real step as telemetry before any predictive compression is attempted.

## Safety Contract

Validation remains dry-run only:

```bash
./scripts/validate_v92_open_web_maneuver_single_shot.sh
```

It asserts:

- pre/post-scroll/post-click maps stay read-only,
- the OS driver returns unarmed scroll/move/click receipts,
- the remapped target is `occlusion_clear=true`,
- no URL change occurs in dry-run mode.

## Armed Gate

The live maneuver shot requires two keys:

```bash
GENESIS_V92_ARMED_CONFIRM=GENESIS_V92_ARMED_OPEN_WEB_MANEUVER \
GENESIS_V92_AUTO_FIRE_CONFIRM=GENESIS_V92_AUTO_FIRE_MANEUVER_SINGLE_SHOT \
./scripts/run_v92_open_web_maneuver_single_shot.sh
```

In armed mode the script posts one scroll wheel action, remaps the page after
settle, selects a visible `link-like` target, posts one click, and requires the
front browser URL to change.
