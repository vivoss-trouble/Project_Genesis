# Genesis v6.2 Calculator Single-Shot Gate

v6.2 converts the v6.1 Calculator map into one controlled OS-driver action.
The default validation remains dry-run.

## Boundary

- One selected Calculator grid cell.
- One `move_mouse`.
- One `click_point`.
- No click sequence.
- No OCR.
- No semantic calculator operation.

## Default Target

```text
calculator-cell-r4-c2
```

Override with:

```bash
GENESIS_V62_TARGET_ID=calculator-cell-r3-c1
```

## Dry-Run Validation

```bash
./scripts/validate_v62_calculator_single_shot.sh
```

The dry run asserts that:

- v6.1 mapping succeeds immediately before fire control.
- the selected target has a valid global CoreGraphics point.
- OS-driver receipts are returned with `posted=false`.
- action ids bind the target id.

## Armed Single Shot

The armed path requires both keys:

```bash
GENESIS_V62_ARMED_CONFIRM=GENESIS_V62_ARMED_CALCULATOR \
GENESIS_V62_AUTO_FIRE_CONFIRM=GENESIS_V62_AUTO_FIRE_SINGLE_SHOT \
  ./scripts/run_v62_calculator_single_shot.sh
```

This posts exactly one move and one click through `genesis-os-driver`.

## Invariant

One shot, one evidence chain. Continuous Calculator fire control is out of scope
until this single-shot path is proven.
