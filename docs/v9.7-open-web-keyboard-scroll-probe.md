# v9.7 Open-Web Keyboard Scroll Probe

## Purpose

v9.6 proved that Safari accepts the CoreGraphics scroll event at the OS-driver
boundary (`posted=true`) but does not move the public Rust Book page. v9.7 does
not change hunter fire control. It adds a separate keyboard-scroll probe to test
whether browser scrolling should switch to a stronger input primitive.

The probe is deliberately atomic:

- no mouse click
- no link activation
- no target hunting
- no assertion mutation
- dry-run by default

## Primitive

`genesis-os-driver` now supports:

```json
{"act":"key_press","key":"page_down"}
```

Supported key names:

- `page_down`
- `page_up`
- `space`
- `arrow_down`
- `arrow_up`

Receipts include the normalized key name and macOS virtual key code:

```json
{
  "action": "key_press",
  "key": {"key": "page_down", "key_code": 121},
  "posted": false
}
```

## Dry-run validation

```bash
./scripts/validate_v97_open_web_keyboard_scroll_probe.sh
```

Expected dry-run invariants:

- `posted=false`
- `url_changed=false`
- three variants: `page_down`, `space`, `arrow_down`
- each key request returns `status=ok`

## Armed telemetry

The live probe is intentionally separated from v9.5 autonomous hunt. It posts
bounded keyboard events only:

```bash
GENESIS_V97_ARMED_CONFIRM=GENESIS_V97_ARMED_OPEN_WEB_KEYBOARD_SCROLL \
GENESIS_V97_AUTO_KEY_CONFIRM=GENESIS_V97_AUTO_KEYBOARD_SCROLL_PROBE \
./scripts/run_v97_open_web_keyboard_scroll_probe.sh
```

Armed mode is fail-fast. If any key changes the front browser URL, the probe
emits `v97_keyboard_scroll_abort` and stops before trying the next key. A
keyboard primitive that can route into browser chrome, search suggestions, or a
different tab is not safe to hand to the hunter controller.

The useful physical constants are:

- `visual_change_detected`
- `mean_common_target_window_y_delta`
- `max_abs_common_target_window_y_delta`
- `target_intersection_ratio`

If keyboard variants produce reliable visual deltas while v9.6 wheel variants
remain zero, v9.x should treat keyboard scrolling as the fallback movement
primitive for Safari open-web hunting.
