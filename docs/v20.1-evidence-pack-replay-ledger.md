# Genesis v20.1 Evidence Pack & Replay Ledger

## Goal

v20.1 adds an immutable evidence wrapper around v20.0 autonomous armed execution. It preserves the causal chain as append-only files so a future failure can be inspected without relying on terminal scrollback.

## Evidence Model

AX JSON is the continuous record. Window screenshots are best-effort keyframes.

Every pack contains:

- `json/00_intent_plan.json`
- `json/*_pre_remap.json`
- `json/*_driver_receipt.json`
- `json/*_post_assert.json`
- `json/50_isr_intervention_log.json`
- `json/99_terminal_scan_report.json`
- `json/99_v20_summary.json`
- `raw/*.jsonl`
- `manifest.json`

Screenshot attempts are stored as:

- `screenshots/00_run_start.png`
- `screenshots/90_final_terminal_state.png`
- matching `json/*_screenshot_status.json`

Screenshot failure is non-fatal. JSON evidence failure is fatal.

## Manifest

`manifest.json` records:

- schema version
- UTC creation time
- git commit
- tool versions
- append-only policy
- screenshot policy
- SHA-256 for every file in the pack

The manifest excludes itself from the hash list so it can be written last.

## Commands

Dry-run evidence pack:

```bash
./scripts/run_v201_evidence_pack.sh
```

Armed evidence pack:

```bash
GENESIS_V201_ARMED_CONFIRM=GENESIS_V201_ARMED_EVIDENCE_PACK \
GENESIS_V201_AUTO_FIRE_CONFIRM=GENESIS_V201_AUTO_FIRE_EVIDENCE_PACK \
./scripts/run_v201_evidence_pack.sh
```

Validation:

```bash
./scripts/validate_v201_evidence_pack.sh
```

## Safety Lines

- Packs are append-only directories.
- Existing pack directories are never overwritten.
- Generated evidence lives under `evidence_packs/` by default and is git-ignored.
- JSON write failure stops the run.
- Screenshot failure is recorded and does not stop the run.
