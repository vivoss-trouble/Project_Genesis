# Genesis v8.4 Open-Web Taxonomy Expansion

v8.4 expands the open-web visual taxonomy without adding fire control.

The first expansion targets two stable document structures:

- `heading`
- `code-block`

## Change

Earlier open-web mapping used color-specific heading detection and treated very
dark pixels as `code-block`. That was enough for the local color-coded fixture
but missed real document headings on public pages.

v8.4 separates dark pixels into two paths:

- large filled dark regions become `code-block`
- dark text rows are merged and promoted to `heading`

This keeps code-block detection geometric while allowing ordinary black
documentation headings to appear in the target set.

## Validation

```bash
./scripts/validate_v84_open_web_taxonomy_expansion.sh
```

The validation remains read-only and asserts:

- at least one `heading`
- at least one `code-block`
- `posted=false`
- `os_driver_active=false`

Scroll-region expansion is intentionally deferred until document structure is
stable across public pages.
