# Genesis v5.2 Native Dummy Window

This is the first controlled macOS-native target for armed OS-driver testing.
It exists to avoid using system apps, whose layouts vary by locale, OS version,
window state, and user configuration.

## Boundary

- It is a real AppKit window.
- It exposes deterministic logical geometry in self-test mode.
- It does not perform vision, OCR, planning, or OS input injection.
- It is safe to validate without Accessibility or Screen Recording permissions.

## Run

Compile and open the target:

```bash
swiftc scripts/native_dummy_window.swift -o /tmp/genesis_native_dummy_window
/tmp/genesis_native_dummy_window
```

The default target is:

```json
{
  "target_id": "native-heal",
  "window": {"x": 160, "y": 160, "width": 420, "height": 260},
  "target_logical_rect": {"x": 150, "y": 95, "width": 120, "height": 70},
  "target_global_logical_center": {"x": 370, "y": 290}
}
```

## Validation

```bash
./scripts/validate_v52_native_dummy_window.sh
```

The validation compiles the AppKit target, runs geometry self-test mode, and then
reuses the v5.1 spatiotemporal matrix to prove the coordinate transform path
still maps into the dry-run OS-driver domain.
