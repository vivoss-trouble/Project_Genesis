# Genesis v14.6 Public ISR E2E

v14.6 stitches the public W3C modal clearance proof into an outer ISR controller
shape. It deliberately initializes the page into the modal-active `S1` state,
freezes the main target context, delegates clearance, and then requires a fresh
remap before the main loop may resume.

## Sequence

1. Open the W3C modal dialog example.
2. Capture the `S0` baseline and locate `Add Delivery Address`.
3. Trigger the W3C modal to create the `S1` occlusion trap.
4. Emit `interrupt_requested=obstacle_clearance`.
5. Freeze the main target context and modal court telemetry.
6. In dry-run, stop before physical clearance.
7. In armed mode, click only the unique legal clearance candidate: `Cancel`.
8. Poll until the modal disappears.
9. Perform a fresh remap and allow resume only if the main target is found
   again with `public_obstacle_seen=false`.

## Main Fire Policy

The default armed path physically clears the obstacle and performs the fresh
remap, but leaves the resumed main target as a projection. This avoids
immediately reopening the W3C modal by clicking `Add Delivery Address` again.

An explicit optional main fire is available with:

```bash
GENESIS_V146_MAIN_FIRE_CONFIRM=GENESIS_V146_MAIN_FIRE_W3C_TRIGGER
```

## Commands

Dry-run validation:

```bash
./scripts/validate_v146_public_isr_e2e.sh
```

Armed ISR E2E:

```bash
GENESIS_V146_ARMED_CONFIRM=GENESIS_V146_ARMED_PUBLIC_ISR_E2E \
GENESIS_V146_AUTO_FIRE_CONFIRM=GENESIS_V146_AUTO_FIRE_PUBLIC_ISR_E2E \
./scripts/run_v146_public_isr_e2e.sh
```
