# Genesis v14.5b W3C Modal Clearance

v14.5b proves the W3C public modal can be activated, adjudicated by the
whitelist court, cleared with one physical click, and verified back in the
ground state.

## Sequence

1. Open the W3C modal dialog example.
2. Prove the baseline: `Add Delivery Address` exists and no modal is active.
3. Trigger the modal with AXPress on `Add Delivery Address`.
4. Poll until the modal reaches `safe_to_arm=true`.
5. In armed mode, move and click the unique legal clearance candidate.
6. Poll every 50ms, up to 1000ms, until the modal disappears.
7. Emit a final receipt proving `target_clear_after=true`.

## Clearance Court

The armed gate is allowed only when the active modal has:

- `public_obstacle_seen=true`
- `occluder_kind=modal`
- `candidate_count >= 2`
- `legal_candidate_count=1`
- `rejected_candidate_count >= 1`
- `selected_clearance=Cancel`

## Commands

Dry-run validation:

```bash
./scripts/validate_v145b_w3c_modal_clearance.sh
```

Armed clearance:

```bash
GENESIS_V145B_ARMED_CONFIRM=GENESIS_V145B_ARMED_W3C_MODAL_CLEARANCE \
GENESIS_V145B_AUTO_FIRE_CONFIRM=GENESIS_V145B_AUTO_FIRE_W3C_MODAL_CLEARANCE \
./scripts/run_v145b_w3c_modal_clearance.sh
```
