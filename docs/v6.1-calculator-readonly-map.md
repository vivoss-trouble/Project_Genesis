# Genesis v6.1 Calculator Read-Only Vision Map

v6.1 is the first real-application visual mapping pass. It targets macOS
Calculator and remains strictly read-only.

## Boundary

- No OCR.
- No template image.
- No OS-driver click.
- No `genesis-core` control-flow change.
- The output is a visual target set and a debug overlay only.

## Pipeline

```text
Calculator window
  -> CGWindowListCreateImage window slice
  -> morphology-style button pixel segmentation
  -> connected components
  -> row/column grid fitting
  -> calculator-cell-rX-cY target set
  -> /tmp/genesis_v61_debug.png overlay
```

The detector does not try to read button labels. It only proves that Genesis can
extract a stable geometric map from a real macOS application without privileged
magenta markers.

## Command

```bash
./scripts/validate_v61_calculator_readonly_map.sh
```

The script opens Calculator, captures its window, emits one
`calculator_readonly_map` event, and asserts that no physical action was posted.

## Debug Evidence

The validation writes:

```text
/tmp/genesis_v61_debug.png
```

The overlay draws detected button bounding boxes and center crosshairs. This
image is the v6.1 visual black box: if the target set looks wrong, the bug is in
the geometry pipeline, not the OS driver or model layer.

## Current Target Shape

Each target is intentionally spatial, not semantic:

```json
{
  "target_id": "calculator-cell-r3-c2",
  "bbox": {"x": 0, "y": 0, "width": 1, "height": 1},
  "global_coregraphics_point": {"x": 0.0, "y": 0.0},
  "confidence": 0.91
}
```

v6.2 may map grid cells to calculator semantics or perform a controlled single
shot. v6.1 only builds the map.
