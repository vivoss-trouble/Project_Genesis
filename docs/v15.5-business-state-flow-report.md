## Scope

This version intentionally limits mutation to one text field and one commit click. The select control is part of the asserted business state path (`standby`) but is not physically changed in this first slice.

## Finding

Safari reported success for `AXValue` mutation on the web text field, but the live DOM value remained empty. v15.5 records that mismatch instead of hiding it, then uses a bounded text-input fallback after focusing the same field through the OS driver. The final assertion is based on the live status node, not the attempted AX write receipt.
