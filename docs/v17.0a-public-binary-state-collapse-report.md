## Scope

This version intentionally avoids form submission. The only mutation under test
is the binary control state itself.

## Finding

The court evidence is the fresh post-click AX remap of the target node, not the
OS driver click receipt by itself. The click receipt proves physical delivery;
the fresh remap proves state collapse.

Two physical constants were captured during armed validation:

- The target must be pulled into the visible viewport with `AXScrollToVisible`
  before OS-driver click delivery. An off-screen target can produce a valid
  move/click receipt while the actual point is clamped to the screen edge.
- The W3C checkbox's authoritative binary state is exposed through `AXValue`.
  `AXSelected` stays false in this fixture and must not outrank `AXValue` in the
  state-source order.
