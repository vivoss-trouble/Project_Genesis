# Genesis v20.0 Autonomous Armed Execution

## Goal

v20.0 arms the v19.0 read-only task plan without trusting stale coordinates. The v19 plan supplies intent, domain lock, step order, and termination conditions. The executor must still resolve every step from a fresh physical view before firing.

## Rule

```text
Plan gives intent.
Fresh remap gives truth.
```

Coordinates inside the v19 plan are audit artifacts only. They are never passed to `os-driver` as click targets.

## Default Target

- URL: `https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/examples/dialog/`
- Plan source: v19.0 public read-only task planner
- Execution primitive: v16.0 public controlled business mutation
- Payload: `42 Genesis Way`
- Terminal evidence: `Verification Result`

## Flow

```text
Run v19 planner
  -> validate domain lock and plan readiness
  -> dry-run stops at execution boundary

Armed:
  -> run v16 execution with the same target contract
  -> step 0 resolves Add Delivery Address from fresh ground-state remap
  -> step 1 resolves Street from fresh modal remap
  -> step 2 resolves Verify Address from fresh form remap
  -> assert Verification Result
  -> assert URL unchanged
```

## Safety Lines

- v19 coordinates are never used as fire coordinates.
- Every v20 step must report `resolved_from_plan_intent=true`.
- Every v20 step must report `stale_plan_coordinates_used=false`.
- Every v20 step must report `fresh_remap_done=true`.
- Dry-run must not start execution.
- Armed mode requires `GENESIS_V200_ARMED_CONFIRM` and `GENESIS_V200_AUTO_FIRE_CONFIRM`.

## Commands

Dry-run:

```bash
./scripts/run_v200_autonomous_armed_execution.sh
```

Armed:

```bash
GENESIS_V200_ARMED_CONFIRM=GENESIS_V200_ARMED_AUTONOMOUS_EXECUTION \
GENESIS_V200_AUTO_FIRE_CONFIRM=GENESIS_V200_AUTO_FIRE_FROM_PLAN \
./scripts/run_v200_autonomous_armed_execution.sh
```

Validation:

```bash
./scripts/validate_v200_autonomous_armed_execution.sh
```
