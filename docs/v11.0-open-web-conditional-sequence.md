# Genesis v11.0 Open-Web Conditional Sequence

v11.0 turns the v10.4 single-shot AX tractor hunt into a bounded conditional
sequence controller.

The controller keeps the same low-level law:

```text
Shadow Map -> AXScrollToVisible -> Remap -> Occlusion Court -> Click -> Assert
```

but requires each step to prove its own post-click universe before the next
step may be loaded.

```json
  }

```

## Boundaries

Dry-run mode:

- opens a fresh Rust Book Safari document,
- projects only the first step,
- resolves the AX target and final click point,
- performs no AX mutation,
- starts no OS driver,
- posts no physical input,
- stops with `stop_reason=dry_run_projection_stop`.

Armed mode:

- posts only one move and one click per sequence step,
- waits for the expected URL after every click,
- waits for two stable Shadow Map signatures before loading the next step,
- records `candidate_count`, `visible_candidate_count`, and `survivor_count`
  for target resolution,
- prefers visible candidates when available, but permits AX traction to pull an
  offscreen target into the viewport before the occlusion court,
- fails closed on target absence, occlusion, URL mismatch, or settle timeout.

## Armed Command

```bash
GENESIS_V110_ARMED_CONFIRM=GENESIS_V110_ARMED_OPEN_WEB_CONDITIONAL_SEQUENCE \
GENESIS_V110_AUTO_FIRE_CONFIRM=GENESIS_V110_AUTO_FIRE_CONDITIONAL_SEQUENCE \
./scripts/run_v110_open_web_conditional_sequence.sh
```

## Validation

```bash
./scripts/validate_v110_open_web_conditional_sequence.sh
```

Validation is dry-run only and proves that the first step can be projected
without mutating WebKit state or posting physical input.
