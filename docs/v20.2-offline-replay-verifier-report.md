# Genesis v20.2 Report

v20.2 implements the offline replay verifier for v20.1 evidence packs.

## Result

- Dry-run evidence replay: expected to pass.
- Armed evidence replay: expected to pass.
- Tamper redline: expected to fail with `TAMPERED_EVIDENCE_FATAL`.

## Evidence Policy

The verifier treats JSON and manifest integrity as hard law. Screenshots remain
part of the hash-sealed evidence pack when present, but screenshot generation
is still governed by v20.1 best-effort capture semantics.

## Time Threshold Decision

The v20.2 court includes `GENESIS_V202_TIME_TEAR_THRESHOLD_MS`, defaulting to
`1000`. Current v20.1 packs do not cryptographically seal per-step timestamps,
so this threshold produces advisory warnings only. This avoids pretending that
mutable filesystem metadata has the same evidentiary strength as manifest
hashes.

## Boundary Discipline

The replay verifier is read-only over the evidence pack. It writes reports only
to `GENESIS_V202_REPORT_PATH` when explicitly requested, and validation stores
temporary reports under `/tmp`.
