## Safety Lines

- Main pagination counters are frozen during ISR.
- ISR is capped at one attempt per pagination step.
- Post-ISR resume requires a fresh remap.
- Terminal target absence is treated as success only after the expected three pagination steps.
- Domain lock is restricted to the local `fixtures/v15` battlefield.

## Validation Target

The validation expects three main pagination clicks and one clearance click:

```json
{
  "main_click_posted_count": 3,
  "isr_triggered_count": 1,
  "isr_step_interventions": [1],
  "final_stop_reason": "target_not_found_terminal_ok"
}
```
