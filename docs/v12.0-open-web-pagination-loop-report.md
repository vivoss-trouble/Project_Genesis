# Genesis v12.0 Open-Web Pagination Loop Report

Date: 2026-05-26

v12.0 establishes a bounded pagination controller on top of the v11.0
conditional sequence primitives.

## Scope

The controller is intentionally an outer Shell state machine. It does not add
memory or strategy to `genesis-os-driver`, and it does not introduce a daemon or
RPC layer.

The loop law is:

```text
Fresh Shadow Map -> Resolve "Next chapter" -> AXScrollToVisible
  -> Remap/Occlusion Court -> Click -> URL/Shadow Settle -> Re-anchor
```

## Red Lines

- `MAX_STEPS`: bounds the patrol and prevents unbounded traversal.
- `MAX_SAME_URL_COUNT`: stops mechanical slip when click does not produce a URL
  transition.
- `URL_DOMAIN_LOCK`: prevents cross-domain drift.
- `TARGET_NOT_FOUND_TERMINAL_OK`: treats missing `Next chapter` as a valid
  pagination terminal state when enabled.
