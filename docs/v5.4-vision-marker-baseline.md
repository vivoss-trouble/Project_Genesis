# Genesis v5.4 Vision Marker Baseline

v5.4 establishes the first deterministic eye-hand bridge on macOS without YOLO,
OCR, or model perception. The goal is to freeze the geometry before adding
probabilistic vision.

## Boundary

- Native Dummy owns the physical target and now renders `native-heal-marker` at
  the exact target center.
- The marker is pure magenta (`RGB 255,0,255`) with a black guard border, while
  the button background remains green. The detector therefore uses a strict
  low-entropy color threshold instead of semantics.
- `genesis-frame-grabber` may emit `marker_detection` when Screen Recording is
  granted and the marker is visible.
- If Screen Recording is denied or the marker is absent, `marker_detection=null`.
  That is a physical observation, not a system failure.

## Detector Constants

```text
marker_id      = native-heal-marker
min_red        = 220
max_green      = 45
min_blue       = 220
marker_size    = 12 logical px
output domain  = CoreGraphics logical coordinates
```

The detector scans the captured physical framebuffer for pixels matching the
marker threshold. It reports the centroid in physical pixels and translates it
into both CoreGraphics and AppKit logical coordinates using the measured display
scale.

## Validation

```bash
./scripts/validate_v54_vision_marker_baseline.sh
```

The validation keeps the physical system safe:

1. Compile and self-test the Native Dummy marker geometry.
2. Run synthetic Rust detector tests against a generated BGRA marker buffer.
3. Run the existing low-entropy vision daemon protocol test.

A fully armed visual click is intentionally left manual until Screen Recording
permission and the marker telemetry are observed on the operator's machine.
