# Genesis v8.7 Sticky/Floating Occlusion Topology

v8.7 closes the last read-only blind spot before open-web kinetic tests:
sticky or fixed visual layers.

The v8 fixture now contains a `sticky-like` shield inside the detected
`scroll-region`. Unlike normal scroll children, this shield does not move with
the scrolled content. The shadow mapper records this difference explicitly:

- `control_kind=sticky-like`
- `container_id=<owning scroll-region>`
- `motion_role=sticky_occluder`
- `scroll_regions[].sticky_target_ids`

This keeps two physical classes separate:

- `scroll_child`: content that remaps when the scroll region moves.
- `sticky_occluder`: container-owned visual armor that stays in place and may
  block future fire projections.

## Redline

```bash
./scripts/validate_v87_sticky_occlusion_topology.sh
```

The validation reuses the v8.6 deterministic scroll remap and asserts:

- contained scroll children move upward,
- sticky occluders stay nearly fixed,
- the scroll-region shell stays nearly fixed,
- all maps and OS driver receipts remain projection-only.

No click, no real page mutation, and no armed OS driver path are used.
