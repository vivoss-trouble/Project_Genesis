# Genesis v17.0b Public Combobox State Collapse Report

## Status

Implemented the public combobox probe, runner, validation script, and
documentation for the W3C APG select-only combobox control.

## Scope

This version intentionally avoids form submission. The only mutation under test
is the combobox value itself.

## Finding

Safari exposes the W3C select-only example as an `AXComboBox`. After expansion,
the popup appears as an `AXList` labelled by the same control, while its options
are exposed as `AXStaticText` children. The court evidence is not the two click
receipts alone; it is the fresh post-option remap proving that the combobox value
changed and that the popup list collapsed.
