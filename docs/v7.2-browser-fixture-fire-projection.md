# Genesis v7.2 Browser Fixture Fire Projection

v7.2 consumes the v7.1 browser target set and projects one selected browser
control into the OS-driver contract without posting physical input.

## Scope

- Reuse `fixtures/v7/browser_fixture.html`.
- Rebuild the browser window map immediately before projection.
- Select one target, defaulting to `browser-button-like-0`.
- Send dry-run `move_mouse` and `click_point` requests to `genesis-os-driver`.
- Assert every receipt has `posted=false`.

No browser state is changed in v7.2.

## Validation

```bash
./scripts/validate_v72_browser_fixture_fire_projection.sh
```

Override the selected target:

```bash
GENESIS_V72_TARGET_ID=browser-input-like-0 \
  ./scripts/validate_v72_browser_fixture_fire_projection.sh
```

## Event Chain

```text
browser_fixture_readonly_map
  -> browser_fixture_fire_projection_target
  -> os_driver_probe
  -> os_driver_move(posted=false)
  -> os_driver_click(posted=false)
  -> v72_browser_fixture_fire_projection_receipts
```

## Invariant

v7.2 is not live fire. It proves coordinate collapse from browser pixels to the
OS-driver action envelope while keeping the physical world untouched.
