# Genesis v12.0 Open-Web Pagination Loop

v12.0 turns the v11.0 conditional sequence into a bounded pagination loop.

The loop keeps the same single-step law:

```text
Fresh Shadow Map -> Resolve "Next chapter" -> AXScrollToVisible
  -> Remap/Occlusion Court -> Click -> URL/Shadow Settle -> Re-anchor
```

but removes the fixed magazine. Each iteration starts from the current browser
state and discards the previous AX tree, DOM state, Shadow Map, and click point.

## Default Boundaries

- `GENESIS_V120_MAX_STEPS=3`
- `GENESIS_V120_MAX_SAME_URL_COUNT=1`
- `GENESIS_V120_URL_DOMAIN_LOCK=rust-lang.org`
- `GENESIS_V120_TARGET_NOT_FOUND_TERMINAL_OK=1`
- `GENESIS_V120_TARGET_TITLE="Next chapter"`

`MAX_STEPS` is a safety fuse, not a semantic end-of-book assertion. Reaching it
after successful steps is a successful bounded patrol with
`stop_reason=max_steps_reached`.

## Terminal Semantics

In a single-shot hunter, a missing target is a failure. In a pagination loop, a
missing `Next chapter` can be the legitimate end of the document chain. v12.0
therefore records:

```json
{
  "event": "v120_pagination_terminal",
  "terminal_success": true,
  "stop_reason": "target_not_found_terminal"
}
```

when `GENESIS_V120_TARGET_NOT_FOUND_TERMINAL_OK=1`.

## Dry-Run

Dry-run mode:

- opens a fresh Rust Book Safari document,
- projects only the first pagination step,
- performs no AX mutation,
- starts no OS driver,
- posts no physical input,
- stops with `stop_reason=dry_run_projection_stop`.

```bash
./scripts/run_v120_open_web_pagination_loop.sh
```

## Armed Mode

Armed mode requires both keys:

```bash
GENESIS_V120_ARMED_CONFIRM=GENESIS_V120_ARMED_OPEN_WEB_PAGINATION_LOOP \
GENESIS_V120_AUTO_FIRE_CONFIRM=GENESIS_V120_AUTO_FIRE_PAGINATION_LOOP \
./scripts/run_v120_open_web_pagination_loop.sh
```

It posts one move and one click per successful step. Every step emits an
independent `v120_pagination_step_summary` with:

- `from_url`
- `to_url`
- `candidate_count`
- `visible_candidate_count`
- `survivor_count`
- `occlusion_clear`
- `move_posted`
- `click_posted`
- `url_changed`
- `shadow_stable`
- `reanchor_ok`

## Validation

```bash
./scripts/validate_v120_open_web_pagination_loop.sh
```

Validation is dry-run only and proves that the first pagination step can be
projected without AX mutation, OS driver activation, or physical input.
