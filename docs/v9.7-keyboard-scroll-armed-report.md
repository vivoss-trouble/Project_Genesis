## Physical Conclusion

The keyboard primitive has stronger OS penetration than the v9.6 scroll-wheel
primitive, but it is not yet safe for autonomous hunting. In the observed armed
run, `page_down` and `arrow_down` changed the front Safari URL away from the
authorized Rust Book page and into an unrelated Gemini page. This indicates a
focus or browser-chrome routing hazard, not a safe content-scroll event.

`space` preserved the URL but produced no visual movement in this run.

## Safety Patch

v9.7 now fail-stops in armed mode after the first variant that changes URL. It
emits:

```json
{"event":"v97_keyboard_scroll_abort","stop_reason":"url_changed_after_key"}
```

The hunter controller must not consume keyboard scrolling until a later probe
proves both conditions:

- `key_posted=true`
- `url_changed=false`
- stable nonzero content delta
