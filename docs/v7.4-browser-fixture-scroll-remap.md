# Genesis v7.4 Browser Fixture Scroll-Remap

v7.4 closes the browser scroll topology loop in projection-only mode:

```text
Map -> Scroll Projection -> Settle -> Map Refresh -> Remap Assertion
```

No physical scroll is posted.

## Fixture State

`fixtures/v7/browser_fixture.html` accepts:

```text
?state=scrolled
```

This creates a deterministic post-scroll visual state without requiring live
input. It keeps v7.4 focused on topology remapping rather than scroll physics.

## Validation

```bash
./scripts/validate_v74_browser_fixture_scroll_remap.sh
```

The validation asserts:

- a pre-scroll map exists
- a `scroll_wheel` projection receipt exists
- `posted=false`
- a post-scroll map exists
- the tracked async target is found again
- the tracked target has a material global Y-coordinate delta

## Invariant

v7.4 proves Genesis can rebuild browser topology after a scroll intent. It does
not yet mutate the browser's live scroll position.
