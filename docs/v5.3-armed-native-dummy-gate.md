# Genesis v5.3 Armed Native Dummy Gate

This stage prepares the first real macOS input shot, but keeps it behind an
explicit human confirmation wall.

## Boundary

- Default mode is dry-run and never posts mouse events.
- Armed mode requires `GENESIS_V53_ARMED_CONFIRM=GENESIS_V53_ARMED_NATIVE_DUMMY`.
- Armed mode also requires typing `FIRE` in the terminal, unless
  `GENESIS_V53_FIRE_CONFIRM=FIRE` is explicitly set for noninteractive testing.
- The OS driver still requires its own `--confirm GENESIS_OS_DRIVER_ARMED`.
- The target is the controlled AppKit native dummy, not a system app.
- Coordinates default to `target_global_logical_center` (`GENESIS_V53_COORDINATE_DOMAIN=appkit`).
  If a local macOS version requires the flipped Quartz domain, rerun with
  `GENESIS_V53_COORDINATE_DOMAIN=quartz`.

## Dry Run

```bash
./scripts/validate_v53_armed_manual_gate.sh
```

This compiles the native dummy, reads its deterministic target geometry, starts
the OS driver daemon in dry-run mode, and sends one `click_point`. The driver
receipt must report `posted=false`.

## Armed Single Shot

Before running armed mode, manually grant Accessibility permission to the
terminal or Codex host that launches `genesis-os-driver`.

```bash
GENESIS_V53_ARMED_CONFIRM=GENESIS_V53_ARMED_NATIVE_DUMMY \
  ./scripts/run_v53_armed_native_dummy.sh
```

If `accessibility_trusted=false`, the script refuses to click. If trusted, it
opens the native dummy, waits for the terminal `FIRE` confirmation, and posts
exactly one click at the target's Quartz logical center.

In armed mode, the script waits for the live Native Dummy window to report its
runtime `target_appkit_screen_center` from `NSWindow.convertToScreen`; the click
is based on that live geometry instead of the static self-test estimate.

If `posted=true` but the native dummy log does not contain `native_dummy_hit`,
rerun once with:

```bash
GENESIS_V53_COORDINATE_DOMAIN=quartz \
GENESIS_V53_ARMED_CONFIRM=GENESIS_V53_ARMED_NATIVE_DUMMY \
  ./scripts/run_v53_armed_native_dummy.sh
```

This explicitly tests the flipped Y-axis domain while keeping the same armed
manual gate.
