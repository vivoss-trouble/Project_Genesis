# Genesis v6.4 Calculator Frame Stability Probe

v6.4 measures UI stillness without changing v6.3 fire control.

## Boundary

- Read-only.
- No OS-driver action.
- No sequence execution.
- No replacement of `GENESIS_V63_SETTLE_MS`.
- No Rust daemon integration yet.

## Probe Rules

Defaults:

```text
sample_interval_ms = 50
max_wait_ms = 1500
stable_frames_required = 3
changed_pixel_ratio_threshold = 0.001
byte_delta_threshold = 8
```

The probe captures the Calculator window repeatedly and compares adjacent frames.
It reports stable only after enough consecutive samples fall below the changed
pixel threshold.

## Command

```bash
./scripts/validate_v64_calculator_frame_stability.sh
```

The validation asserts that Calculator stabilizes without any physical action.

## Next Boundary

v6.5 may replace the fixed v6.3 settle sleep with this probe, but v6.4 only
collects timing evidence.
