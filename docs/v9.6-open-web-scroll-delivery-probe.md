# v9.6 Open-Web Scroll Delivery Probe

v9.6 isolates scroll delivery from hunter policy. It tests whether macOS
CoreGraphics scroll events are actually absorbed by the front Safari page before
the autonomous hunter is allowed to depend on them.

## Driver Changes

`genesis-os-driver` now pins scroll events to the requested physical point with
`CGEventSetLocation` after warping and moving the cursor there. Scroll requests
also accept an optional unit:

```json
{"act":"scroll_wheel","x":1010.4,"y":585.0,"dy":66,"scroll_unit":"pixel"}
{"act":"scroll_wheel","x":1010.4,"y":585.0,"dy":3,"scroll_unit":"line"}
```

If `scroll_unit` is omitted, the driver preserves the historical default:
`pixel`.

## Probe Contract

```bash
./scripts/run_v96_open_web_scroll_delivery_probe.sh
```

Default mode is dry-run. The probe:

- opens the Rust Book page,
- maps the page before each variant,
- sends an unarmed `scroll_wheel` request,
- remaps the page after the request,
- records whether the visual target set changed.

The default variant set is:

```text
pixel:66,line:3,pixel:240,line:6
```

Validation uses a shorter dry-run pair:

```bash
./scripts/validate_v96_open_web_scroll_delivery_probe.sh
```

## Armed Probe

The armed probe posts scroll events only. It never clicks.

```bash
GENESIS_V96_ARMED_CONFIRM=GENESIS_V96_ARMED_OPEN_WEB_SCROLL_PROBE \
GENESIS_V96_AUTO_SCROLL_CONFIRM=GENESIS_V96_AUTO_SCROLL_DELIVERY_PROBE \
./scripts/run_v96_open_web_scroll_delivery_probe.sh
```

The useful armed signal is not URL transition. It is the difference between
pre-scroll and post-scroll visual maps:

- `scroll_posted=true`
- `receipt_scroll_unit=pixel|line`
- `visual_change_detected=true|false`
- `target_intersection_ratio`
- `mean_common_target_window_y_delta`

This keeps v9.6 as a delivery probe, not a hunter controller.
