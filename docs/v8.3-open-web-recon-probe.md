# Genesis v8.3 Open-Web Recon Probe

v8.3 combines shadow mapping and drift telemetry into a read-only risk report
for public web pages.

## Invariant

```text
public URL -> shadow maps -> drift telemetry -> risk report
posted=false
os_driver_active=false
```

The probe does not open an OS-driver socket and does not emit mouse, keyboard,
or scroll events.

## Risk Report

The final `open_web_recon_risk_report` includes:

- `target_count`
- `taxonomy_coverage`
- `taxonomy_counts`
- `max_content_drift_px`
- `max_window_origin_drift_px`
- `kind_switch_count`
- `missing_observations`
- `mean_capture_latency_ms`
- `safe_to_consider_fire`
- `primary_threat`

## Deterministic Validation

The redline uses the local v8 static document sample:

```bash
./scripts/validate_v83_open_web_recon_probe.sh
```

## Rust Book Recon

Public probes are telemetry, not redline gates:

```bash
GENESIS_V83_URL="https://doc.rust-lang.org/book/" \
GENESIS_V83_WINDOW_TITLE="Rust" \
GENESIS_V83_SAMPLE_COUNT=20 \
GENESIS_V83_SAMPLE_INTERVAL_SEC=0.2 \
  ./scripts/run_v83_open_web_recon_probe.sh
```

If the report says `safe_to_consider_fire=false`, the threat list is the next
engineering input. v8.4 should not introduce pre-fire correction until public
recon data proves what kind of instability exists.
