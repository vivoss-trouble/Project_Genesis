# Genesis v21.1 Public Standard Form Armed Chain

v21.1 isolates the Wikipedia v21.0b safe failure and proves the armed public
execution spine on a simpler public target: `https://httpbin.org/forms/post`.

The goal is not to solve modern JavaScript search boxes. The goal is to prove
the unified chain in real network conditions:

```text
v19 read-only intent plan
  -> fresh remap before each step
  -> public form text mutation
  -> physical submit click
  -> response-state assertion
  -> immutable evidence pack
  -> offline replay verification
```

## Contract

- The v19 plan uses `GENESIS_V190_PLAN_PROFILE=httpbin_standard_form`.
- Plan coordinates are advisory only. v21.1 re-resolves the input and submit
  target before acting.
- Armed mode must produce `url_changed=true` and
  `response_state_asserted=true`.
- Evidence packs use `run_profile=v21.1-standard-public-form`.
- The replay verifier accepts `raw/v211_exec_results.jsonl` as the kinetic
  source for this profile.

## Commands

Dry-run:

```bash
./scripts/run_v211_public_standard_form.sh
```

Armed:

```bash
GENESIS_V211_ARMED_CONFIRM=GENESIS_V211_ARMED_PUBLIC_STANDARD_FORM \
GENESIS_V211_AUTO_FIRE_CONFIRM=GENESIS_V211_AUTO_FIRE_PUBLIC_STANDARD_FORM \
./scripts/run_v211_public_standard_form.sh
```

The default test value is `Genesis`. Override with `GENESIS_V211_INPUT_VALUE`
when a run needs a different payload.

Validation:

```bash
./scripts/validate_v211_public_standard_form.sh
```
