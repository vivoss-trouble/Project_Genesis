# v9.1 Open-Web Static Single-Shot Gate

v9.1 is the first open-web kinetic gate. It keeps the first shot deliberately
static: no scroll, no predictive correction, no multi-step navigation.

The default target is the Rust Book:

```bash
https://doc.rust-lang.org/book/
```

The gate selects one visible `link-like` target from the current shadow map,
rejects it if its center is covered by any `sticky-like` occluder, and projects
the final CoreGraphics point through the OS driver.

## Safety Contract

Validation remains dry-run only:

```bash
./scripts/validate_v91_open_web_static_single_shot.sh
```

It asserts:

- pre/post shadow maps stay read-only (`posted=false`, `os_driver_active=false`),
- target selection is `occlusion_clear=true`,
- OS driver move/click receipts remain `posted=false`,
- the browser URL does not change in dry-run mode.

## Armed Gate

The first real open-web shot requires two explicit keys:

```bash
GENESIS_V91_ARMED_CONFIRM=GENESIS_V91_ARMED_OPEN_WEB \
GENESIS_V91_AUTO_FIRE_CONFIRM=GENESIS_V91_AUTO_FIRE_STATIC_SINGLE_SHOT \
./scripts/run_v91_open_web_static_single_shot.sh
```

In armed mode the post-shot assertion requires the front browser URL to change.
This keeps the first public Web proof focused on a low-risk navigation link,
not on form submission, mutation, account state, or remote write actions.
