# Genesis v13.0 Obstacle Clearance Probe

v13.0 introduces an independent obstacle clearance probe. It does not modify the
main AX traction probe.

## Separation

```text
Traction probe:
  Find and pull the main target.

Obstacle probe:
  Given an occluded target context, scan the local modal/occluder region for a
  whitelisted close control.

Main controller:
  Freezes the main target, calls the obstacle probe, remaps the original target,
  and resumes only when `occlusion_clear=true`.
```

## White List Court

The probe only considers candidates that satisfy all constraints:

```text
label in {"Close", "Dismiss", "Not now", "Reject all", "Decline"}
role in {"AXButton", "AXLink"}
candidate center inside occluder/modal bbox
label does not contain {"accept", "subscribe", "continue", "agree"}
```

If no unique legal candidate exists, the correct outcome is:

```json
{
  "stop_reason": "obstacle_unresolved"
}
```

## Dry-Run Validation

```bash
./scripts/validate_v130_obstacle_clearance_probe.sh
```

Expected dry-run facts:

- `target_found=true`
- `occlusion_clear=false`
- `candidate_count=4`
- `legal_candidate_count=1`
- `rejected_candidate_count=3`
- selected clearance is `Close`
- `ax_mutation_attempted=false`
- `click_posted=false`

## Armed Fixture Command

```bash
GENESIS_V130_ARMED_CONFIRM=GENESIS_V130_ARMED_OBSTACLE_CLEARANCE \
GENESIS_V130_AUTO_FIRE_CONFIRM=GENESIS_V130_AUTO_FIRE_OBSTACLE_CLEARANCE \
./scripts/run_v130_obstacle_clearance_probe.sh
```

Armed mode may click exactly one whitelisted candidate, then reruns the probe and
requires `target_clear_after=true`.
