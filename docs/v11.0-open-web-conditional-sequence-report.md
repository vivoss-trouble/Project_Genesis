## Defensive Findings

Two failures were intentionally preserved as design pressure:

- A wrong-window AX selection appeared when multiple Safari documents matched
  broad title needles. The AX probe now prefers `AXMain`/`AXFocused` matching
  windows and each sequence step supplies its own source title needle.
- A strict pre-traction visible requirement rejected the `Next chapter` target
  because it started offscreen. The policy now prefers visible candidates, then
  lets `AXScrollToVisible` perform traction, and only the post-traction
  occlusion court is mandatory.
