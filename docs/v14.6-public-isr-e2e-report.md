# Genesis v14.6 Public ISR E2E Report

## Design

v14.6 uses the deterministic W3C modal as a public ISR exercise field. The
trap is set explicitly with `Add Delivery Address`, so the test verifies ISR
stitching instead of adding a new cross-page trigger variable.

## Dry-Run Contract

Expected dry-run summary:

```json
{
  "event": "v146_public_isr_e2e_summary",
  "armed": false,
  "interrupt_requested": true,
  "main_loop_frozen": true,
  "isr_complete": false,
  "resume_allowed": false,
  "requires_fresh_v12_remap": false,
  "main_fire_mode": "projection_only",
  "main_click_posted": false,
  "stop_reason": "dry_run_isr_projection_stop",
  "posted": false,
  "physical_input_posted": false
}
```

## Armed Contract

The armed path must prove:

- `child_click_posted=true`
- `child_target_clear_after=true`
- `fresh_remap_done=true`
- `resume_allowed=true`
- `requires_fresh_v12_remap=true`
- `main_fire_mode=projection_only`

The resumed main target is not clicked by default because it is the W3C modal
trigger and would intentionally return the page to `S1`.

Observed armed summary:

```json
{
  "event": "v146_public_isr_e2e_summary",
  "armed": true,
  "interrupt_requested": true,
  "main_loop_frozen": true,
  "isr_complete": true,

  "posted": true,

```
