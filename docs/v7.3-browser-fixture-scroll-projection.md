# Genesis v7.3 Browser Fixture Scroll Projection

v7.3 adds a first-class scroll projection to the OS-driver contract and uses it
against the controlled browser fixture in dry-run mode.

## Scope

- Reuse the v7.1 browser target set.
- Select `browser-scroll-container-0`.
- Emit one `scroll_wheel` OS-driver request with `dx` and `dy`.
- Keep the OS driver unarmed.
- Assert `posted=false` and preserve the scroll delta in the receipt.

## Validation

```bash
./scripts/validate_v73_browser_fixture_scroll_projection.sh
```

Override the dry-run scroll vector:

```bash
GENESIS_V73_SCROLL_DY=-360 \
  ./scripts/validate_v73_browser_fixture_scroll_projection.sh
```

## Event Chain

```text
browser_fixture_readonly_map
  -> browser_fixture_scroll_projection_target
  -> os_driver_probe
  -> os_driver_scroll(posted=false, scroll_delta={dx,dy})
  -> v73_browser_fixture_scroll_projection_receipts
```

## Invariant

Scroll is now its own audited physical action shape. It is not modeled as a
click, and v7.3 does not mutate browser state.
