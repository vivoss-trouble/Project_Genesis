# Genesis v5.6 Window-Scoped Vision Capture

v5.6 moves the deterministic marker detector from full-display framebuffer
sampling to controlled WindowServer sampling for the Native Dummy window.

## Boundary

- `genesis-core` is unchanged.
- `genesis-os-driver` is unchanged.
- `genesis-frame-grabber` still requires macOS Screen Recording permission.
- Window capture is enabled only when `GENESIS_VISION_WINDOW_ID` is present.
- The detector output is window-local; the single-shot gate translates it to a
  global CoreGraphics point immediately before calling the OS driver.

## Native Window Anchor

`native_dummy_window.swift` now emits `window_number` in its `ready` payload.
The v5.5/v5.6 single-shot script uses that WindowServer id to request a direct
window image from CoreGraphics:

```text
CGWindowListCreateImage(CGRectNull, kCGWindowListOptionIncludingWindow, window_id, kCGWindowImageBoundsIgnoreFraming)
```

This avoids terminal Z-order contamination in the full-display framebuffer.

## Coordinate Transform

For a detected window-local CoreGraphics point:

```text
global_x = window_frame.x + local_x
global_y = screen_height - (window_frame.y + window_frame.height) + local_y
```

The result is the global CoreGraphics coordinate consumed by `genesis-os-driver`.

## Dry Run

```bash
GENESIS_V55_AUTO_VISIBLE=1 \
  ./scripts/run_v55_vision_marker_single_shot.sh
```

Expected evidence:

- `capture_scope: "window"`
- `window_id` equal to the Native Dummy `window_number`
- non-null `marker_detection`
- `vision_action_point.coregraphics_logical_point` near the Native Dummy marker
- OS driver receipt with `posted=false`

## Armed Controlled Shot

Only for the controlled Native Dummy target:

```bash
GENESIS_V55_AUTO_VISIBLE=1 \
GENESIS_V55_ARMED_CONFIRM=GENESIS_V55_ARMED_VISION_MARKER \
GENESIS_V55_AUTO_FIRE_CONFIRM=GENESIS_V55_AUTO_FIRE_NATIVE_DUMMY \
  ./scripts/run_v55_vision_marker_single_shot.sh
```

The script still refuses to click when marker detection is absent or when
Accessibility is not trusted.

## Validation

```bash
./scripts/validate_v56_window_scoped_capture.sh
```

The validation is intentionally dry-run only. It asserts window-scoped capture,
marker detection, global CoreGraphics point transformation, and `posted=false`
OS-driver receipts.
